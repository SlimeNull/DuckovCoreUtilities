Core Utilities 是《逃离鸭科夫》的综合实用功能模组，集中提供物品信息、库存整理、地图辅助、战斗反馈和界面优化。所有功能均可独立启用和配置。

[h1]订阅与配置[/h1]

[olist]
[*]订阅此模组及其必需物品。
[*]推荐同时订阅 [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3789464208]Duckov Mod Settings[/url]。
[*]启动游戏，在“设置 > 模组设置”中选择 Core Utilities，即可分别调整每项功能。
[/olist]

未订阅或未启用 Duckov Mod Settings 时，Core Utilities 仍可按默认配置运行，但无法在游戏内修改选项。除“击杀记录”和“小地图”外，其余功能默认启用。

[h1]功能[/h1]

[h2]物品与经济[/h2]

[list]
[*][b]显示物品价格[/b]：在物品信息中显示商人出售价格或物品原价。
[*][b]黑市比价[/b]：在黑市报价下方显示百分比和金额差异。供应报价与物品原价比较；需求报价可选择与商人回购价或物品原价比较，并计算剩余交易数量的总差额。
[*][b]显示库存数量[/b]：在物品信息中显示背包和仓库内同类物品的数量。
[*][b]显示物品品质[/b]：使用边框、背景或角标表现物品品质。
[*][b]显示物品可用次数[/b]：对使用耐久度的物品显示当前、最大以及耐久损耗后的可用次数。
[*][b]更好的钥匙和蓝图标识[/b]：为已经录入的钥匙、钥匙卡和蓝图显示绿色勾选标识，并支持自定义标识颜色。
[*][b]显示任务需求道具[/b]：在物品信息中汇总未完成任务、天赋和建筑所需数量；按住 [b]Shift[/b] 可查看具体需求来源。
[/list]

[h2]战利品与库存[/h2]

[list]
[*][b]战利品轮廓[/b]：为当前可见的战利品箱和地面物品显示轮廓，可使用品质颜色、呼吸效果、周期和最低透明度。
[*][b]库存排序按钮[/b]：为背包和仓库添加按价值、重量和价重比排序的按钮，并整理可堆叠物品。
[*][b]自动关闭背包[/b]：在玩家移动或受到伤害时自动关闭背包及拾取界面，两种触发条件可分别设置。
[/list]

[h2]战斗与 HUD[/h2]

[list]
[*][b]瞄准时淡出 HUD[/b]：瞄准时降低 HUD 透明度，可设置目标透明度和过渡时间。
[*][b]弹药量准星颜色[/b]：弹匣剩余比例进入警告区间后逐渐改变准星颜色，并支持自定义起始与耗尽颜色。
[*][b]低生命值屏幕阴影[/b]：生命值降低时显示屏幕边缘阴影，可配置颜色、宽度和强度阈值。
[*][b]击杀记录[/b]：在 HUD 中显示近期击杀记录，可设置格式、显示时长和最大条数。此功能默认关闭。
[*][b]显示手雷爆炸范围[/b]：显示投掷物的实际爆炸范围和引信进度，并为烟雾区域显示剩余持续时间；颜色和各类进度显示均可配置。
[/list]

[h2]地图与时间[/h2]

[list]
[*][b]小地图[/b]：在关卡内的时间与风暴信息下方显示圆角小地图，支持固定方向或跟随玩家朝向、尺寸、透明度以及按键缩放。此功能默认关闭。
[*][b]显示 BOSS 位置[/b]：在地图上标记存活的 BOSS，可显示名称并自定义颜色。“静态”模式保留其初始生成位置，“动态”模式在地图打开时更新实时位置。
[*][b]快点鸭时间[/b]：在睡眠界面添加两个可自定义的固定时间按钮，以及“睡到雨天”“睡到风暴 I”“睡到风暴 II”和“睡到风暴结束”。寻找雨天时可按 [b]Esc[/b] 取消。
[*][b]任务收藏[/b]：右键点击任务可切换收藏状态；收藏任务显示星星或心形标记并自动置顶，收藏记录按存档保存。
[/list]

[h2]窗口行为[/h2]

[list]
[*][b]游戏失去焦点时[/b]：游戏窗口失去焦点后自动静音，并可选择打开暂停菜单。
[/list]

[h1]本地化[/h1]

设置名称和主要新增界面文本支持简体中文、繁体中文与英文，并会在游戏切换语言后刷新。

[h1]贡献翻译[/h1]

欢迎为此模组补充其他语言：

[olist]
[*]复制项目中的 [b]Localization/SettingsText.resx[/b]，也可以从已有翻译文件开始。
[*]将副本命名为 [b]SettingsText.<语言标识>.resx[/b]，例如 [b]ja[/b]、[b]ko[/b]、[b]ru[/b]。
[*]只翻译每个资源项的值，保留所有键名以及 [b]{0}[/b]、[b]{1}[/b] 等占位符。
[*]完成后向 [url=https://github.com/SlimeNull/DuckovMods]GitHub 仓库[/url]提交 Pull Request。
[/olist]
